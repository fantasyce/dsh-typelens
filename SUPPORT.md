# Support

- Ask usage and integration questions in GitHub Discussions.
- Report reproducible defects with the bug-report issue form.
- Propose adapters or compatibility cases with the integration issue form.
- Report vulnerabilities privately according to `SECURITY.md`.

Include the TypeLens, DSH, Node.js, operating-system, and framework versions,
plus the smallest synthetic reproduction. Do not publish credentials,
proprietary source, full model requests, or private paths.
